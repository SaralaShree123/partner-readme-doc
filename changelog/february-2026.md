# Support for Usernames / BSUID

Meta is introducing Usernames on WhatsApp in 2026, which will be associated with a Business Scoped User ID (BSUID). Gupshup will support this change in phases.

## Phase 1 – Pre-GA (Starting March 31, 2026)

By default, Gupshup will continue passing only the phone number. Partners who want to start working with usernames early will have an optional capability to fetch the BSUID.

## Phase 2 – GA Rollout (Expected in H2 2026)

Gupshup will share a detailed transition plan ahead of this phase.

# Security Update About Account-Level API Keys on Gupshup

Account-level API keys will no longer be displayed in the Gupshup interfaces. App-level credentials are strongly recommended.

# DEPRECATION : 'Allow category change' flag for template creation

It is recommended to not pass this field in your template creation requests.

## Gupshup Product Updates

### Coexistence Support

The Coex Sync API is now live and ready for use. We are targeting a full General Availability (GA) rollout for Coexistence feature by the end of June 2026. For details on sync API, please refer to our Sync API documentation.

### Username / BSUID Updates

The partner API to enable/disable receiving BSUID payloads in incoming webhooks is now live at app level.

While reserving of usernames by businesses and sending message to BSUID is still under testing by Meta, support for this will be provided by Gupshup in the coming weeks.

### Security Enhancements

While API keys and App tokens are now visible only once — upon generation / regeneration — a bug related to non-admins not being able to generate app tokens from partner portal is now fixed.

**ALERT:** Partners using password to generate partner token should note that they must prepare for adoption of client secret method to generate partner token as the legacy method will be deprecated on Oct 31, 2026.

## Gupshup Pricing / Policy Updates

### Policy Update: Phase-out of System-Assigned Overdraft Facility for Wallets

Effective July 01, 2026: The current maximum limit of the system-calculated overdraft facility will continue to remain unchanged for existing wallets and will no longer be automatically revised upward going forward.

### ALERT: Accept Gupshup Partner Terms of Use by 30th June 2026 to avoid disruption

Partners who do not accept the Terms by this date may start losing some partner portal features such as app creation, etc.

# Time to live support in User initiated calling template and session messages

You can now set time-to-live for user initiated calling relating messaging CTAs.

# Waba Health API now provides Meta phone number ID

You can now get Meta phone number ID in the waba health API along with app ID.

# Phase 1 - Support for Usernames / BSUID is now ready

Partners can choose to enable a flag to receive BSUID-related data along with phone numbers in incoming messages and delivery reports (DLRs).

# Security Enhancements : New and Upcoming

Key updates include IP Whitelisting via UI, private key-based authentication for bulk key rotation, mandatory MFA on gupshup.ai, app-level API keys only, and webhook notifications for critical changes.

# Gupshup Pricing / Policy Updates

## DEPRECATED : 'Allow category change' flag for template creation

As Meta has deprecated this feature during template application, Gupshup also does not support or pass this field to Meta any more.

## REMINDER : Gupshup Partner Terms of Use – Action Required

Acceptance must be completed by a partner account admin. Recommended deadline: April 30 2026.

## Gupshup Product Updates

### New field now available for Recharge Invoice

A new field is now available in Billing Details of Wallet, allowing you to display tax registration information directly on recharge invoices.

### Delete Sandbox App API Now Available

Partners can now programmatically delete sandbox apps using the newly available API on the Partner Portal.

### API for enabling/disabling BSUID flag available now

Partners can choose to enable a flag to receive BSUID-related data along with phone numbers in incoming messages and delivery reports (DLRs).

### Docs Updates: WhatsApp Single-Product Template Messages and Product Card Carousel Templates

New documentation has been added for sending WhatsApp Single-Product Template Messages and Product Card Carousel Templates via Gupshup APIs.

## Security Improvements

- One-Time Visibility for App Tokens & API Keys
- MFA Enforcement and Password Rotation (mandatory on Partner.Gupshup.io starting 31st May 2026)
- Reduced Login Session Duration (24 hours to 12 hours on Gupshup.ai)

## Gupshup Pricing / Policy Updates

### Update: Platform Upgrade for Improved Reliability & Messaging Performance

Please whitelist the IPs mentioned in Gupshup IP allowlisting documentation.

### WhatsApp API Version Upgrade to v24.0

For version 24.0 and newer requests, the status messages webhook will no longer include the `conversation` object, unless the webhook is for a message sent during an open Free Entry Point window.

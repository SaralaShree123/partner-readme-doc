# Enabling Group Functionality

To enable group functionality for your app, follow these steps:

1. Enable Group Functionality: Inform the engineering team to enable it on the app level (If Postpaid billing is not handled, then it cannot be enabled)

Once these steps are completed, you can use the APIs to manage groups

<br />

1. We support passthrough payloads for group messaging.
2. Supported message types: Text, media, text-based templates, and media-based templates
3. Supported webhooks: Message SENT | Message FAILED | Message DELIVERED | Incoming Messages

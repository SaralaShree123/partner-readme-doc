| Glossary                                                                                                                                                                                          |
| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Create App](https://partner-docs.gupshup.io/reference/post_partner-app-1): This API is used to create a new WABA onboarding outside of Gupshup UI.                                               |
| [Update App](https://partner-docs.gupshup.io/reference/put_partner-app-appid-1) : This API is used to update the WABA onboarding outside of Gupshup UI.                                           |
| [Get App](https://partner-docs.gupshup.io/reference/get_partner-app-appid-details-1) : Used to fetch the app details based on appId.                                                              |
| [Get App List](https://partner-docs.gupshup.io/reference/get_partner-app-list-1) : Used to fetch the list of all the apps for the account based on the query parameters.                          |
| [Set CallBack](https://partner-docs.gupshup.io/reference/put_partner-app-appid-callback-1) : This endpoint is used to configure a customer callback URL for the application.                      |
| [Set Contact Details](https://partner-docs.gupshup.io/reference/put_partner-app-appid-onboarding-contact-1) : This endpoint is used for Contact details.                                          |
| [Resend Verification Link](https://partner-docs.gupshup.io/reference/post_partner-app-appid-onboarding-contact-email-resend-1) : This endpoint is used to resend the verification link.           |
| [Generate Embed Signed Link](https://partner-docs.gupshup.io/reference/get_partner-app-appid-onboarding-embed-link-1) : This endpoint is used to generate the embed signed link.                  |
| [Mark App for Migration](https://partner-docs.gupshup.io/reference/post_partner-app-appid-onboarding-phonemigration-1) : This API is used to mark an app as migrated from another BSP to Gupshup. |

## Request Parameters

| Key           | Description                      | Value                     | Data type | Required/Optional | Constraints                                |
| :------------ | :------------------------------- | :------------------------ | :-------- | :---------------- | :----------------------------------------- |
| Authorization | Access Token for the application | \{\{PARTNER\_APP\_TOKEN}} | String    | Required          | Should be a valid Partner App Access Token |
| appId         | App id of the app                | \{\{APP\_ID}}             | String    | Required          | The Id should be a valid app Id of Gupshup |
| flowId        | Flow Id                          | \{\{FLOW\_ID}}            | String    | Required          | Flow Id generated by Meta                  |
| file          | File path                        | \{\{FILE\_PATH}}          | file      | Required          |                                            |

## Sample Request

```curl
curl --location --request PUT 'https://partner.gupshup.io/partner/app/{{APP_ID}}/flows/{{FLOW_ID}}/assets' \
--header 'Authorization: {{PARTNER_APP_TOKEN}}' \
--header 'Content-Type: application/json' \
--form 'file={{FILE_PATH}}'
```

## Sample Response

```
{
    "status": "success",
    "success": true,
    "validation_errors": []
}
```

APIs are available to manage the entire lifecycle flow supported for CAPI apps.

| Glossary                                                                                                                                                                                                                                                                                        |
| :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-address-message-2#/">Address Message</Anchor>: Address messages give users a simpler way to share the shipping address with the business on WhatsApp.                                         |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-audio-message-6">Audio Message</Anchor>: Displays an audio icon, and plays when the WhatsApp user taps it.                                                                                    |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-contact-message-6">Contact Message</Anchor>: Allows users to send rich contact information directly to WhatsApp users, such as names, phone numbers, physical addresses, and email addresses. |
| [Flow Message](/reference/post_partner-app-appid-v3-flow-message-6): User can send a flow message after creating a WhatsApp flow.                                                                                                                                |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-image-message">Image Message</Anchor>: This endpoint allows the user to send an image message to a WhatsApp user.                                                                             |
| [Interactive Message](/reference/post_partner-app-appid-v3-interactive-message): This endpoint allows the user to send interactive messages to a WhatsApp user.                                                                                                  |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-reaction-message">Reaction Message</Anchor>: This endpoint allows the user to send a reaction message to a WhatsApp user.                                                                     |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-sticker-message">Sticker Message</Anchor>: This endpoint allows the user to send sticker messages.                                                                                            |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-text-message">Text Message</Anchor>: This endpoint allows the user to send a text message to a WhatsApp user.                                                                                 |
| <Anchor target="_blank" href="/reference/post_partner-app-appid-v3-video-message">Video Message</Anchor>: This endpoint allows the user to send a video message to a WhatsApp user.                                                                              |
| [Document Message](/reference/senddocumentmessage): This endpoint allows the user to send a document message to a WhatsApp user.                                                                                                                          |

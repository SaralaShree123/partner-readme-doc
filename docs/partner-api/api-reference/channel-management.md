# Channel Management

Create and manage WhatsApp channel applications for your customers. Use these APIs to create apps, update app settings, generate Embedded Signup links, and filter the apps linked to your partner account.

## Create App

> Create a new WhatsApp channel application under your partner account for a customer WABA.

→ Full endpoint & Try It: [/reference/post_partner-app](/reference/post_partner-app)

## Update application

> Update configuration for an existing partner application.

→ Full endpoint & Try It: [/reference/put_partner-app-appid](/reference/put_partner-app-appid)

## Generate Embed Signed Link

> Generate a signed Embedded Signup link so customers can onboard WhatsApp from your product UI.

→ Full endpoint & Try It: [/reference/get_partner-app-appid-onboarding-embed-link](/reference/get_partner-app-appid-onboarding-embed-link)

## Filter app list

> Filter and list partner applications with query parameters for operational views and tooling.

→ Full endpoint & Try It: [/reference/get_partner-app-list](/reference/get_partner-app-list)

# Introduction

This guide describes how the partner portal of Gupshup helps the existing partner to become a Tech provider.  The setup process enables non-TPP (Technology Provider Partners) to integrate their solution ID with Gupshup's platform.  By entering the joint solution ID, the existing partner becomes a Tech Provider.

## Setup Joint Solution ID with Gupshup

1. Navigate to the [https://www.gupshup.io/partner/](https://www.gupshup.io/partner/). 
2. Click on the profile drop-down on the top right and select **Settings**.

   <Image align="left" width="50% " src="https://files.readme.io/90cba71-a.png" />
3. Click on **Add new solution**.

   <Image align="left" width="70% " src="https://files.readme.io/535d744-b.png" />
4. Enter the **Meta Solution ID** and **Solution Name** created on the [Meta Developer Portal](https://support.gupshup.io/hc/en-us/articles/33097921935769-Tech-Provider-Setup-for-Non-TPP-partners-on-Gupshup).

   <Image align="left" className="border" width="70% " border={true} src="https://files.readme.io/02b0034-c.png" />

   <Image align="center" width="7px" src="https://files.readme.io/16df2a1-c.png" />
5. The **Solution ID** is mapped upon request and sent to the partner support team for approval.

   <Image align="left" width="70% " src="https://files.readme.io/dc83818-d.png" />
6. The support team verifies the solution ID on the Meta Developer Portal.  The solution ID request is accepted on the Meta portal and mapped to the partner ID on Gupshup.
7. A confirmation email is sent by the support team once the request is accepted and mapped to the partner ID on Gupshup.
8. If the request is rejected, the partner can **re-submit** the modified solution ID.
9. Upon approval displays as **APPROVED** in the status field of the Settings tab on the Partner portal.

   <Image align="left" className="border" width="70% " border={true} src="https://files.readme.io/9f55f2b-e.png" />

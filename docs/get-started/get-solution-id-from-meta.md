# Signup as a Meta Tech Provider

### Step 1: Create a Meta Business Account

<Anchor label="Create " target="_blank" href="https://developers.facebook.com/docs/whatsapp/solution-providers/get-started-for-tech-providers#step-1--create-a-business-portfolio">Create </Anchor>or use an existing Meta Business Account to ensure all the necessary business details (address, website, email, etc.) are provided during the verification process.

**Note:**

* Your business is limited to a maximum of two Meta Business Accounts.
* Make sure all information is accurate to avoid rejection during business verification. Onboarding WhatsApp services may fail if your business account is not in good standing with Meta.

### STEP 5 : Complete App Review

Once you have completed business verification, you can submit your app for App Review. You’ll need to complete the following tasks:

1. Review your app settings

   Submit the App Settings in left nav drawer

   Add your privacy policy and terms of service URLs. Select **Messaging** category.

   ![](https://files.readme.io/42ddb282cd2ee1e381dc5ae822b127189b276bf389f5fecc88dc942ab5c3d98d-image.png)
2. Create and submit videos of your app  
   To pass App Review, you need to submit video evidence of your capabilities to send messages and manage templates. The first video must show a message created and sent from your app and received in the WhatsApp client (mobile app or web app). The second video must show your app being used to create a message template. As an alternative, you can capture a screen recording of your current integration with Gupshup / APIs being used by you to send a message to a WhatsApp user number you have added as a test recipient number, in lieu of sending a message using your or your partner’s app. Similarly, you can capture a screen recording of the WhatsApp Manager being used by you to create a template message.
3. Submit documentation for App Review  
   Get approval to access advanced permissions and features so that your can manage your clients’ accounts and information. App Review is the process that will grant you advanced access to the following permissions which are required to become a Tech Provider.
   1. Advanced access to whatsapp_business_messaging will allow you to send messages for customers
   2. Advanced access to whatsapp_business_management allows you to onboard customers and manage their assets.

      Click the Begin App Review button to start your submission.
4. Review your app settings

# Setup/Add New Joint Solution ID with Gupshup

If you are an existing Gupshup partner and already have a joint solution ID with Gupshup, please read this <Anchor label="guide" target="_blank" href="https://support.gupshup.io/hc/en-us/articles/46824303546393">guide</Anchor> to understand how to add a solution ID with OneDirect.

#### IF YOU ARE ALREADY A GUPSHUP PARTNER  AND NEVER HAD A JOINT SOLUTION ID WITH GUPSHUP

1. Navigate to [https://partner.gupshup.io/web/login](https://partner.gupshup.io/web/login)
2. On signing in, go to Settings (under the drop down on top right below language selection)
3. Click on 'Add new solution'.

![](https://files.readme.io/02eed93d3b78821b89d2c33130bd0e14818a43cdda77b66c5c2babb2a4194e28-image.png)

4. Enter the Meta Solution ID and Name created in the above steps on Meta Developer Portal

![](https://files.readme.io/44ad55776c8950a0c7b7b61e0da578e3a6c45d5e19bd8214d58bfd3660c4e23b-image.png)

5. Solution ID mapping request will be sent to the partner support team for approval.

![](https://files.readme.io/4a01e1402645ae31421ff1b5ed558539dd9f0f33bf2117dc54169f2a236d8dec-image.png)

NOTE : At this point, you can continue to create apps and do go live on Self Serve portal. Apps will go live without the joint solution ID till your request is approved.

6. Support team will verify the solution ID on Meta Developer Portal. If request from the given solution ID is received, the solution request will be accepted on the Meta portal as well as the solution ID will be mapped to your partner ID on Gupshup.
7. Support will accept or reject the request triggering a confirmation email to you. In case it is rejected, they can re-submit the modified solution ID. If application is approved, it will show as approved in the Settings tab on Partner portal.

<br />

##### Phone number onboarding with Joint Solution ID

If you have multiple solution IDs, the default Solution ID will get applied while app creation and going live. Partners who use the self serve portal can continue to use the same portal, ensuring to follow below steps in the right order for joint solution ID mapping to the apps

1. Create app on Self serve portal
2. Link app to your partner ID [THIS IS A KEY STEP]
3. Only then, go live with the app which will register the approved joint solution ID set as default on Partner Portal

In case, partner ID is not linked to the app, the approved joint solution ID of partner will NOT be registered with Meta, thus it will not show for attribution with the Tech Provider at Meta.

Also, old live apps linked to same partner ID will not be linked to the solution ID automatically with this process.

<br />

#### IF YOU ARE A NEW OR POTENTIAL GUPSHUP PARTNER

#### **Signup as a Gupshup ISV**

1. Navigate to the [https://partner.gupshup.io/web/login](https://partner.gupshup.io/web/login)
2. After signup, you will need to verify your email ID and set a new password.
3. Login again with the set credentials.
4. Fill all the necessary fields provided to proceed ahead.
5. Read all the Gupshup terms and conditions. You must agree to them if you move ahead. And then fill in the other details.

![](https://files.readme.io/4986da1e0b2df8f52c467b3b06501abfc676ea503a022d72480bc2dffbd55e20-image.png)

6. Enter the Meta Solution ID and Name created in the above steps on Meta Developer Portal

![](https://files.readme.io/25a404ca8605b6957ff7601e0a2fc0a3188e65adebd70e8dc1c9f1cffaded67c-image.png)

<br />

7. Partner creation request will be sent to the partner support team for approval.

![](https://files.readme.io/464d559cba3ce55ba6c602a1fe2e18cf002ed3c27c700d9f5d1634f8c0654322-image.png)

8. Support team will verify the solution ID on Meta Developer Portal. If request from the given solution ID is received, the solution request will be accepted on the Meta portal as well as the ISV will be approved on Gupshup. The solution will be displayed in the solutions panel as 'Active' only once Gupshup accepts it

![](https://files.readme.io/94cf1d698c0fd38d7fd14fb1814d0771f6a9ca28a31890db6d22bca2235422a6-image.png)

<br />

9. Support will accept or reject the request triggering a confirmation email to you. If your request is approved, the remaining tabs will be enabled for the partner. In case the partner application is rejected, they can re-submit their application with modified solution ID.

To know how to use the partner portal - create WABA or manage wallet, refer this <Anchor label="article" target="_blank" href="https://support.gupshup.io/hc/en-us/articles/29522963720473">article</Anchor>.

Note: Partner Portal supports the Admin and the User role. The Admin role has the advantage of adding more users.

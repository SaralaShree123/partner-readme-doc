# Gupshup Partner Documentation (Git Mirror)

ReadMe Git-sync export of [Gupshup Partner Documentation](https://partner-docs.gupshup.io/), version **v1.0**.

## Structure

| Folder | Contents |
|--------|----------|
| `docs/` | Guides (Partner Portal, Voice, Payments, Security, etc.) |
| `reference/` | API Reference pages and OpenAPI specs |
| `changelog/` | Release notes |
| `custom_blocks/` | Reusable ReadMe components |

## ReadMe sync

- Branch **`v1.0`** must match the ReadMe project version name.
- Enable **Bi-Directional Sync** in ReadMe → Settings → Git Connection → GitHub.
